# Dream Agent Guidelines

- Apply the installed **Ponytail full** skill before drafting issues, planning, coding or UI work. Use Grill Me if the task is materially ambiguous.
- Keep prompt instructions in English; reply in the user's language when identifiable.
- Prefer native ChatGPT UI and minimal diagrams; avoid large custom UIs or invented host APIs.
- Keep changes small, preserve existing plugin identity and metadata, and avoid unnecessary dependencies.
- Read the plugin manifest and skill references before edits. Maintain both manifests consistently.
- Use Issue → plan approval → feature branch → checks → PR; merge only with explicit approval.
- The public repository is source control, not automatic ChatGPT deployment. Don't claim deployment unless Plugin Creator confirms it.
- Never publish tokens, secrets or personal contact information.
